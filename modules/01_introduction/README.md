# Module 01 — Introduction to OpenUEM

## ဤ module တွင် ဘာတွေ သင်မည်လဲ

- Endpoint management ဆိုသည်မှာ ဘာလဲ၊ ဘယ်ပြဿနာများကို ဖြေရှင်းသည်
- Self-hosted နှင့် SaaS endpoint manager ကွာခြားချက်
- OpenUEM ၏ component များနှင့် ၎င်းတို့ ချိတ်ဆက်ပုံ
- Endpoint lifecycle ၏ အဆင့်များ
- OpenUEM က ပေးသော စွမ်းရည်များ
- Lab တစ်ခု မတည်ဆောက်မီ ပြင်ဆင်ရမည့် အချက်များ

## ဖိုင်များ

- `explanation.md` — အသေးစိတ် ရှင်းလင်းချက် (figure နှစ်ခု အပါအဝင်)
- `exercise.md` — လေ့ကျင့်ခန်း ခြောက်ခု
- `solution.md` — အဖြေများ
- `lab.py` — လေ့ကျင့်ခန်းများကို စစ်ဆေးသော deterministic lab

## Lab run ခြင်း

```bash
python3 modules/01_introduction/lab.py
```
