# Module 01 — Introduction to OpenUEM

## What you will learn in this module

- What endpoint management is and which problems it solves
- The difference between a self-hosted and a SaaS endpoint manager
- The components of OpenUEM and how they connect
- The stages of the endpoint lifecycle
- The capabilities OpenUEM provides
- What to prepare before building a lab

## Files

- `explanation.md` — the detailed explanation (including two figures)
- `exercise.md` — six exercises
- `solution.md` — the answers
- `lab.py` — a deterministic lab that checks the exercises

## Running the lab

```bash
python3 modules/01_introduction/lab.py
```
