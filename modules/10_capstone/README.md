# Module 10 — Capstone: ဇာတ်လမ်းတစ်ခုလုံး

ဤ module သည် ယခင် module ရှစ်ခုတွင် သီးခြားစီ သင်ယူခဲ့သော ကျွမ်းကျင်မှုများကို
အဖွဲ့အစည်းတစ်ခု၏ ဖြန့်ကျက်မှု အစီအစဉ်တစ်ခုအဖြစ် ပေါင်းစပ်သည်။
ခေါင်းစဉ်အသစ် မရှိပါ။ သင်ယူပြီးသော အစိတ်အပိုင်းများကို အစဉ်လိုက်
အသုံးချခြင်းသာ ဖြစ်သည်။

## ဇာတ်လမ်း အတိုချုပ်

`openuem.example` အဖွဲ့အစည်းတွင် ဌာနချုပ် (ရန်ကုန်) နှင့် ဌာနခွဲ (မန္တလေး)
နှစ်ခု ရှိသည်။ endpoint စုစုပေါင်း ၂၇ ခုကို Windows, Linux, macOS သုံးမျိုးဖြင့်
စီမံသည်။ server သည် Linux host တစ်ခုတည်းတွင် PostgreSQL နှင့် compose
stack အဖြစ် လည်ပတ်သည်။ အဖွဲ့သည် agent များကို wave သုံးခုဖြင့်
enrollment လုပ်သည်။ ထို့နောက် software baseline ကို package နှင့် profile
ဖြင့် ပေးပို့သည်။ patch wave တစ်ခုကို maintenance window အတွင်း
လုပ်ဆောင်သည်။ နောက်ဆုံးတွင် certificate ပြောင်းလဲမှုကြောင့် agent များ
report မပို့တော့သော ဖြစ်ရပ်တစ်ခု ဖြစ်ပေါ်ပြီး အဖွဲ့က ရှာဖွေ ပြန်လည်
ထူထောင်သည်။

## ဤ module တွင် ဘာတွေ လုပ်မည်လဲ

- ဆောက်လုပ်မှု အစီအစဉ်နှင့် လက်ခံနိုင်မှု စံနှုန်းများ သတ်မှတ်ခြင်း
- enrollment wave စီမံချက် ရေးဆွဲခြင်း
- software baseline နှင့် patch wave ဖြန့်ခြင်း
- ဖြစ်ရပ်တစ်ခုကို အလွှာလိုက် ရှာဖွေခြင်း
- review အတွက် သက်သေ အစုအဝေး စုစည်းခြင်း

## ဖိုင်များ

- `explanation.md` — ဇာတ်လမ်းအပြည့်အစုံ, လက်ခံနိုင်မှု စံနှုန်းများ, figure သုံးခု
- `exercise.md` — လေ့ကျင့်ခန်း ခြောက်ခု
- `solution.md` — `lab.py` ၏ အမှန် output နှင့် တွဲဖက် အဖြေများ
- `lab.py` — လေ့ကျင့်ခန်း ခြောက်ခုကို စစ်ဆေးသော deterministic lab

## မစတင်မီ လိုအပ်ချက်များ

- module 01 မှ 08 အထိ ဖတ်ပြီးဖြစ်ရမည်။
- PostgreSQL, compose, certificate, agent install အခြေခံ သဘောတရား
  များကို သိရှိထားရမည်။
- Python 3 ကို run နိုင်သော စက်တစ်ခု လိုအပ်သည်။ lab သည် standard
  library သာ အသုံးပြုပြီး ကွန်ရက် မလိုအပ်ပါ။

## Lab run ခြင်း

```bash
python3 modules/10_capstone/lab.py
```

မျှော်မှန်းရလဒ်:

```text
# simulated output — illustrative
[OK] exercise_1 — 11/12 readiness checks pass and the CA validity gap blocks the build
...
[PASS] All 6/6 exercises passed successfully.
```

ဤ module ကို ပြီးဆုံးသည်ဟု သတ်မှတ်သည်။
