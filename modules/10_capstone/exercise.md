ဤ module ၏ လေ့ကျင့်ခန်း ခြောက်ခုသည် ဇာတ်လမ်းတစ်ခုတည်းကို အဆင့်လိုက်
ဖြတ်သန်းသည်။ လေ့ကျင့်ခန်း တစ်ခုစီသည် `lab.py` ၏ function တစ်ခုနှင့်
ကိုက်ညီသည်။ လေ့ကျင့်ခန်း တစ်ခုကို မပြီးမချင်း နောက်တစ်ခုသို့ မကူးရ။

```bash
python3 modules/10_capstone/lab.py
```

ဤ command က လေ့ကျင့်ခန်း ခြောက်ခုလုံးကို အစဉ်လိုက် လုပ်ဆောင်ပြီး
`[PASS] All 6/6 exercises passed successfully.` ဖြင့် အဆုံးသတ်သည်။

## Exercise 1 — Readiness checklist ကို စစ်ဆေးခြင်း

`exercise_1()` ရှိ `checks` ဇယားကို ဖတ်ပါ။ စစ်ဆေးချက် ၁၂ ခု ရှိပြီး
တစ်ခုစီတွင် သတ်မှတ်ချက် (`eq`, `ge`, `le`) နှင့် တန်ဖိုး နှစ်ခု ပါဝင်သည်။

လုပ်ဆောင်ရန်:

1. စစ်ဆေးချက် တစ်ခုစီကို သတ်မှတ်ချက်အတိုင်း အကဲဖြတ်ပါ။
2. ကျရှုံးသော စစ်ဆေးချက် အမည်များကို စာရင်း ပြုပါ။
3. ကျရှုံးမှု တစ်ခု ရှိလျှင် ဆောက်လုပ်မှု gate ကို `NOT-READY` ဟု
   သတ်မှတ်ပါ။ ကျရှုံးမှု မရှိလျှင် `READY` ဖြစ်သည်။
4. ကျရှုံးသော စစ်ဆေးချက်သည် နောက်ပိုင်း ဖြစ်ရပ်နှင့် မည်သို့ ဆက်စပ်သည်
   ကို တစ်ကြောင်း ရေးပါ။

မေးခွန်း: readiness checklist က အတားအဆီး တစ်ခုကို ဖော်ထုတ်နိုင်ခြင်းသည်
ဘာကြောင့် အရေးကြီးသနည်း။

## Exercise 2 — Enrollment wave စီမံချက် ရေးဆွဲခြင်း

`exercise_2()` သည် endpoint စာရင်းကို `_endpoints()` မှ ရယူသည်။
ဌာနချုပ်တွင် Windows ၁၀, Linux ၅, macOS ၃ ရှိပြီး ဌာနခွဲတွင်
Windows ၅, Linux ၃, macOS ၁ ရှိသည်။

လုပ်ဆောင်ရန်:

1. pilot wave ကို ဌာနချုပ်မှ ရွေးပါ။ platform တစ်မျိုးလျှင် တစ်ခု
   ဖြစ်ရမည်။
2. ကျန် ဌာနချုပ် endpoint များကို ဒုတိယ wave အဖြစ် သတ်မှတ်ပါ။
3. ဌာနခွဲ endpoint အားလုံးကို တတိယ wave အဖြစ် သတ်မှတ်ပါ။
4. wave တစ်ခုစီတွင် endpoint အရေအတွက်, platform အစုံ, ထပ်နေမှု ရှိ မရှိ
   နှင့် စုစုပေါင်း လွှမ်းခြုံမှုကို စစ်ဆေးပါ။
5. wave တစ်ခုလျှင် endpoint ၂၀ ကျော် မဖြစ်ရ ဟူသော ကန့်သတ်ချက်ကို
   စစ်ဆေးပါ။

မေးခွန်း: pilot wave တွင် platform သုံးမျိုး ပါဝင်ရခြင်း၏ အကြောင်းရင်းကို
ရှင်းပြပါ။

## Exercise 3 — Rollout gate ကို အကဲဖြတ်ခြင်း

`exercise_3()` တွင် တိုင်းတာမှု သုံးကြိမ် ပါဝင်သည်။ gate သတ်မှတ်ချက်
လေးခုမှာ အောက်ပါအတိုင်း ဖြစ်သည်။

| Gate | သတ်မှတ်ချက် |
|---|---|
| G1 | လက်ရှိအချိန် 01:00–05:00 window အတွင်း |
| G2 | reporting ၉၀% နှင့် အထက် |
| G3 | validation ကျရှုံးမှု သုည |
| G4 | ဖွင့်ထားသော P1 ဖြစ်ရပ် မရှိ |

လုပ်ဆောင်ရန်:

1. တိုင်းတာမှု တစ်ခုစီအတွက် gate လေးခုကို အစဉ်လိုက် စစ်ပါ။
2. မပြည့်သော gate တစ်ခုစီ၏ အမည်ကို မှတ်တမ်းတင်ပါ။
3. ဆုံးဖြတ်ချက် (`GO` သို့မဟုတ် `HOLD`) ကို ထုတ်ပါ။
4. သုံးကြိမ်၏ ဆုံးဖြတ်ချက် အစဉ်ကို တစ်ကြောင်း ရေးပါ။
5. ဒုတိယ တိုင်းတာမှု `GO` ဖြစ်ရသည့် အကြောင်းရင်းကို ရှင်းပါ။

မေးခွန်း: တတိယ တိုင်းတာမှုသည် အခြေအနေ အားလုံး ပြည့်မီပါလျက်
ဘာကြောင့် `HOLD` ဖြစ်သနည်း။

## Exercise 4 — လိုက်နာမှု သက်သေ အနှစ်ချုပ် ထုတ်ခြင်း

`exercise_4()` တွင် မလိုက်နာသော endpoint သုံးခု၏ စာရင်း ပါဝင်သည်။
တစ်ခုစီတွင် အမျိုးအစား (`software-baseline` သို့မဟုတ် `patch-level`)
နှင့် အတိုချုပ် အကြောင်းရင်း ရှိသည်။

လုပ်ဆောင်ရန်:

1. platform တစ်မျိုးစီအတွက် စုစုပေါင်း, လိုက်နာသူ အရေအတွက် နှင့်
   ရာခိုင်နှုန်းကို တွက်ပါ။
2. စုစုပေါင်း လိုက်နာမှု ရာခိုင်နှုန်းကို ဒသမ တစ်နေရာ ထိ ဖော်ပါ။
3. မလိုက်နာသော endpoint များကို အက္ခရာ အစဉ်အတိုင်း စာရင်း ပြုပါ။
4. အနိမ့်ဆုံး ရာခိုင်နှုန်း ရှိသော platform ကို ဖော်ထုတ်ပါ။

မေးခွန်း: စုစုပေါင်း ၈၈.၉% သည် လက်ခံနိုင်သော ကိန်းဂဏန်း ဖြစ်ပါလျက်
platform တစ်ခုတည်း၏ ကိန်းဂဏန်းကို ဘာကြောင့် သီးခြား ကြည့်ရသနည်း။

## Exercise 5 — ဖြစ်ရပ်၏ အမြစ်အကြောင်းရင်း ရွေးချယ်ခြင်း

`exercise_5()` တွင် လေ့လာတွေ့ရှိချက် (`signals`) ဆယ်ခုနှင့်
အကြောင်းရင်း ငါးခု (`candidates`) ပါဝင်သည်။ အကြောင်းရင်း တစ်ခုစီတွင်
"ထို အကြောင်းရင်း မှန်လျှင် မည်သည့် အချက်အလက် ပေါ်လာမည်" ဟူသော
မျှော်မှန်းချက် စာရင်း ရှိသည်။

လုပ်ဆောင်ရန်:

1. အကြောင်းရင်း တစ်ခုစီအတွက် မျှော်မှန်းချက် မည်မျှ ကိုက်ညီသည်ကို
   ရေတွက်ပါ။
2. ကိုက်ညီမှု အချိုးကို score အဖြစ် တွက်ပါ။
3. score အမြင့်ဆုံး အကြောင်းရင်းကို ရွေးပါ။
4. ကျန် အကြောင်းရင်း လေးခုကို မည်သည့် အထောက်အထားက ဖယ်ထုတ်သည်ကို
   တစ်ကြောင်းစီ ရေးပါ။
5. ပြန်လည် ထူထောင်မှု အစီအစဉ်ရှိ service များ၏ အစဉ်ကို စစ်ဆေးပါ။

မေးခွန်း: အစားထိုးမခံရသော endpoint ၄ ခု ဆက်လက် report ပို့နေခြင်းက
မည်သည့် အကြောင်းရင်းကို ဖယ်ထုတ်သနည်း။

## Exercise 6 — အဆုံးသတ် scorecard တွက်ချက်ခြင်း

`exercise_6()` တွင် နယ်ပယ် ခြောက်ခု၏ အလေးချိန် နှင့် အမှတ် ပါဝင်သည်။
အလေးချိန် စုစုပေါင်းသည် ၁၀၀ ဖြစ်ရမည်။

လုပ်ဆောင်ရန်:

1. နယ်ပယ် တစ်ခုစီ၏ ပံ့ပိုးမှု (အလေးချိန် × အမှတ် ÷ ၁၀၀) ကို တွက်ပါ။
2. အလေးချိန် စုစုပေါင်း ၁၀၀ ဖြစ် မဖြစ် စစ်ပါ။
3. အလေးချိန်ဖြင့် တွက်ထားသော စုစုပေါင်း အမှတ်ကို ဒသမ တစ်နေရာ ထိ
   ဖော်ပါ။
4. အမှတ် အနိမ့်ဆုံး နယ်ပယ်ကို ဖော်ထုတ်ပါ။
5. အောက်ပါ သတ်မှတ်ချက်ဖြင့် အောင်မြင် / မအောင်မြင် ဆုံးဖြတ်ပါ။
   စုစုပေါင်း ၇၅ နှင့် အထက် ဖြစ်ရမည်။ နယ်ပယ် တစ်ခုမျှ ၆၀ အောက်
   မဖြစ်ရ။

မေးခွန်း: နယ်ပယ် တစ်ခု ၆၀ အောက် ဖြစ်လျှင် စုစုပေါင်း အမှတ် မြင့်နေပါလျက်
ဘာကြောင့် မအောင်မြင်ဟု သတ်မှတ်သနည်း။
