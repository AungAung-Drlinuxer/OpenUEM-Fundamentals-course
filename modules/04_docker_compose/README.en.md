# Module 04 — Docker/Podman Deployment

## What this module covers

- When the container route is appropriate
- The `openuem-docker` repository and preparing `.env`
- The required environment variables
- Starting and verifying with `docker compose up -d`
- Hosts override in a lab without DNS
- Reverse proxy and ports
- Upgrade, teardown, and the comparison with native deployment

## Files

- `explanation.md` — detailed explanation (two figures)
- `exercise.md` — six exercises
- `solution.md` — solutions
- `lab.py` — deterministic check

## Running the lab

```bash
python3 modules/04_docker_compose/lab.py
```
