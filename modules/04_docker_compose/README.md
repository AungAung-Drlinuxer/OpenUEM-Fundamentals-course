# Module 04 — Docker/Podman Deployment

## ဤ module တွင် ဘာတွေ သင်မည်လဲ

- Container လမ်းကြောင်း သင့်လျော်သော အခြေအနေများ
- `openuem-docker` repository နှင့် `.env` ပြင်ဆင်ခြင်း
- လိုအပ်သော environment variable များ
- `docker compose up -d` ဖြင့် စတင်ခြင်းနှင့် စစ်ဆေးခြင်း
- DNS မရှိသော lab တွင် hosts override
- Reverse proxy နှင့် port များ
- Upgrade၊ teardown နှင့် native deployment နှင့် နှိုင်းယှဉ်ချက်

## ဖိုင်များ

- `explanation.md` — အသေးစိတ် ရှင်းလင်းချက် (figure နှစ်ခု)
- `exercise.md` — လေ့ကျင့်ခန်း ခြောက်ခု
- `solution.md` — အဖြေများ
- `lab.py` — deterministic စစ်ဆေးမှု

## Lab run ခြင်း

```bash
python3 modules/04_docker_compose/lab.py
```
