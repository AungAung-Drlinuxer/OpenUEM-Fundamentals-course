# Module 07 — Device management basics

## ဤ module ၏ ရည်မှန်းချက်

Enrollment ပြီးဆုံးသော endpoint တစ်ခုကို နေ့စဉ် စီမံခန့်ခွဲပုံကို ဤ module တွင် လေ့လာသည်။ Inventory tab များက မည်သည့်မေးခွန်းကို ဖြေဆိုသည်၊ package တစ်ခုကို platform တစ်ခုစီတွင် မည်သည့် engine ဖြင့် ဖြန့်သည်၊ profile ဖြင့် ဆန္ဒရှိသော အခြေအနေကို မည်သို့ ထိန်းသိမ်းသည်၊ မည်သည့် လုပ်ဆောင်ချက်ကို အဝေးမှ လုပ်နိုင်သည် ဆိုသည်တို့ ပါဝင်သည်။

## ကြိုတင် လိုအပ်ချက်

- Module 06 ပြီးဆုံးထားခြင်း (agent Enabled အခြေအနေသို့ ရောက်ရှိထားခြင်း)
- Python 3.10 သို့မဟုတ် အထက် (lab အတွက်)
- OpenUEM server မလိုအပ်ပါ။ Lab သည် လုံးဝ offline ဖြစ်သည်။

## သင်ယူပြီးနောက် လုပ်နိုင်ရမည့် ကျွမ်းကျင်မှုများ

1. Inventory tab တစ်ခုစီက ဖြေဆိုသော မေးခွန်းကို ဖော်ပြနိုင်ခြင်း။
2. Windows, Linux နှင့် macOS အတွက် မှန်ကန်သော deployment engine ကို ရွေးချယ်နိုင်ခြင်း။
3. Offline agent အတွက် တန်းစီနေသော request ကို ရှင်းပြနိုင်ခြင်း။
4. Profile task တစ်ခုသည် ပစ်မှတ် platform တွင် တရားဝင် ဖြစ် မဖြစ် စစ်ဆေးနိုင်ခြင်း။
5. Tag filter ဖြင့် ပစ်မှတ် အုပ်စုကို ရွေးချယ်နိုင်ခြင်း။
6. Health flag များကို စုစည်းပြီး ဦးစားပေး သတ်မှတ်နိုင်ခြင်း။

```bash
python3 modules/07_device_management/lab.py
```

Script သည် အောင်မြင်ပါက အောက်ပါစာကြောင်းဖြင့် ပြီးဆုံးသည်။

```text
[PASS] All 6/6 exercises passed successfully.
```

## ဖတ်ရှုပုံ အကြံပြုချက်

`explanation.md` ကို အပိုင်း 7.1 မှ 7.5 အထိ ဖတ်ပြီးနောက် `exercise.md` ၏ လေ့ကျင့်ခန်း 1 နှင့် 2 ကို လုပ်ပါ။ ထို့နောက် 7.6 မှ 7.8 ဖတ်ပြီး လေ့ကျင့်ခန်း 3 နှင့် 4 ကို ဆက်လုပ်ပါ။ နောက်ဆုံး အပိုင်း 7.9 မှ 7.12 ဖတ်ပြီး လေ့ကျင့်ခန်း 5 နှင့် 6 ကို ပြီးဆုံးပါ။ အချိန် မိနစ် 90 ခန့် လိုအပ်သည်။

## မှတ်ချက်

ဤ module ရှိ command output အားလုံးသည် `# simulated output — illustrative` ဟု အမှတ်အသားပြုထားသော သင်ကြားရေး fixture များ ဖြစ်သည်။ Lab ၏ data သည်လည်း သင်ကြားရေးအတွက် ဖန်တီးထားသော ဥပမာ ဖြစ်သည်၊ မည်သည့် တကယ့် fleet ၏ တိုင်းတာချက်မျှ မဟုတ်ပါ။ Version အလိုက် ပြောင်းလဲနိုင်သော အချက်များကို `explanation.md` ၏ `Technical review notes` တွင် မှတ်သားထားသည်။
