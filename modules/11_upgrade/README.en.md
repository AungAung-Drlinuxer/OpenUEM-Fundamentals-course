# Module 11 — Server and Agent Upgrades

## What this module covers

- Upgrading server components from the console
- The different upgrade path for Docker deployments
- Bulk agent upgrades from the console
- Upgrade states (Pending / In Progress / Success / Error)
- Rolling back to a previous release
- Pre-upgrade and post-upgrade checklists

## Files

- `explanation.en.md` — full explanation (two figures)
- `exercise.en.md` — six exercises
- `solution.en.md` — answers
- `lab.py` — deterministic checker for the exercises

## Running the lab

```bash
python3 modules/11_upgrade/lab.py
```
