# Module 11 — Server နှင့် Agent Upgrade

## ဤ module တွင် ဘာတွေ သင်မည်လဲ

- Server component များကို console မှ upgrade လုပ်ခြင်း
- Docker deployment တွင် upgrade လုပ်သည့် ကွဲပြားသော လမ်းကြောင်း
- Agent များကို console မှ အစုလိုက် upgrade လုပ်ခြင်း
- Upgrade အခြေအနေ (Pending / In Progress / Success / Error)
- ပြန်လည် လျှော့ချခြင်း (rollback)
- Upgrade မတိုင်မီနှင့် ပြီးနောက် စစ်ဆေးရန် စာရင်း

## ဖိုင်များ

- `explanation.md` — အသေးစိတ် ရှင်းလင်းချက် (figure နှစ်ခု)
- `exercise.md` — လေ့ကျင့်ခန်း ခြောက်ခု
- `solution.md` — အဖြေများ
- `lab.py` — deterministic စစ်ဆေးမှု

## Lab run ခြင်း

```bash
python3 modules/11_upgrade/lab.py
```
