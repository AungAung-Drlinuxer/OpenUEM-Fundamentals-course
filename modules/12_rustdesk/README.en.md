# Module 12 — RustDesk Remote Desktop

## What this module covers

- The three remote assistance paths in OpenUEM (VNC, RDP, RustDesk)
- How RustDesk works: ID server, relay server, public key
- Running the RustDesk server (hbbs/hbbr) with Docker
- Ports and firewall rules
- Installing the Windows and Linux clients
- One-click sessions through OpenUEM's RustDesk integration
- Security cautions

## Files

- `explanation.en.md` — full explanation (two figures)
- `exercise.en.md` — six exercises
- `solution.en.md` — answers
- `lab.py` — deterministic checker for the exercises

## Running the lab

```bash
python3 modules/12_rustdesk/lab.py
```
