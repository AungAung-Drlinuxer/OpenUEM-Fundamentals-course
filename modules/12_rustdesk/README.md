# Module 12 — RustDesk Remote Desktop

## ဤ module တွင် ဘာတွေ သင်မည်လဲ

- OpenUEM ၏ remote assistance လမ်းကြောင်း သုံးမျိုး (VNC, RDP, RustDesk)
- RustDesk ၏ လုပ်ဆောင်ပုံ — ID server၊ relay server၊ public key
- RustDesk Server (hbbs/hbbr) ကို Docker ဖြင့် တည်ဆောက်ခြင်း
- Port များနှင့် firewall စည်းမျဉ်း
- Windows နှင့် Linux client များ install လုပ်ခြင်း
- OpenUEM ၏ RustDesk integration ဖြင့် တစ်ခလုတ်တည်း ချိတ်ဆက်ခြင်း
- လုံခြုံရေး သတိပြုချက်များ

## ဖိုင်များ

- `explanation.md` — အသေးစိတ် ရှင်းလင်းချက် (figure နှစ်ခု)
- `exercise.md` — လေ့ကျင့်ခန်း ခြောက်ခု
- `solution.md` — အဖြေများ
- `lab.py` — deterministic စစ်ဆေးမှု

## Lab run ခြင်း

```bash
python3 modules/12_rustdesk/lab.py
```
