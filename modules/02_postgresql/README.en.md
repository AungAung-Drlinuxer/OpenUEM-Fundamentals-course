# Module 02 — Preparing PostgreSQL (Ubuntu 24.04)

## What you will learn in this module

- Why PostgreSQL must be prepared first for OpenUEM
- Installing PostgreSQL on Ubuntu 24.04
- Creating the database and role (`psql`)
- The connection URI and percent-encoding
- `pg_hba.conf` authentication
- Testing, backup, and clean reinstall
- How this compares with the database in a Compose deployment

## Files

- `explanation.en.md` — detailed explanation (two figures)
- `exercise.en.md` — six exercises
- `solution.en.md` — solutions
- `lab.py` — deterministic checks

## Running the lab

```bash
python3 modules/02_postgresql/lab.py
```
