# Module 02 — PostgreSQL ပြင်ဆင်ခြင်း (Ubuntu 24.04)

## ဤ module တွင် ဘာတွေ သင်မည်လဲ

- OpenUEM အတွက် PostgreSQL ကို ဘာကြောင့် ဦးစွာ ပြင်ဆင်ရသည်
- Ubuntu 24.04 တွင် PostgreSQL install လုပ်ခြင်း
- Database နှင့် role ဖန်တီးခြင်း (`psql`)
- Connection URI နှင့် percent-encoding
- `pg_hba.conf` authentication
- စမ်းသပ်ခြင်း၊ backup၊ ပြန်လည် ရှင်းလင်းခြင်း
- Compose deployment ၏ database နှင့် နှိုင်းယှဉ်ချက်

## ဖိုင်များ

- `explanation.md` — အသေးစိတ် ရှင်းလင်းချက် (figure နှစ်ခု)
- `exercise.md` — လေ့ကျင့်ခန်း ခြောက်ခု
- `solution.md` — အဖြေများ
- `lab.py` — deterministic စစ်ဆေးမှု

## Lab run ခြင်း

```bash
python3 modules/02_postgresql/lab.py
```
